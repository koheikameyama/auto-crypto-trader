# Round 6: US 10Y Yield (TNX) 統合 — 5-signal Continuous Sizing

**作成日:** 2026-04-23
**前提:** R5 で BH 超え達成 (Sharpe 0.933 vs 0.871, drop 24.3%)、ただし Sharpe 1.0 未達 & 6.5y スコープ
**目的:** US 10Y yield を 5 つ目の signal として追加、Sharpe ≥ 1.0 と full 10y 検証を狙う
**想定工数:** 1.5-2 時間（既存 framework 流用）

---

## 1. 仮説

**H5「10Y yield は crypto の macro risk signal のコア」:**
- Rising 10Y yield = tight monetary conditions = risk-off = crypto bearish
- Falling 10Y yield = easing / recession fear = mixed (risk-off short-term, risk-on medium)
- DXY と相関するが独立情報を持つ（DXY = 通貨市場、10Y = 金利期待）
- 2022 の crypto 下落は主に 10Y 急上昇が引き金 → 特に bear 検知に有効

→ 5 つ目の signal として continuous sizing v2 に追加で、Sharpe 押し上げ可能性あり

---

## 2. スコープ変更: 6.5y → 10y

R5 は funding rate（2019-10〜）制約で 6.5 年スコープ。R6 は **2 つの WF** を実施:

### WF-A: Full 10y (funding なし)
- Signals: onchain + DXY + VIX + **10Y yield** (4-signal、funding 除外)
- 期間: 2016-04〜2026-04 (10 年)
- 比較: BH 10y (Sharpe 1.102)
- **ここで Sharpe ≥ 1.0 と BH 1.102 超えを目指す**

### WF-B: 6.5y (funding あり)
- Signals: onchain + DXY + VIX + funding + **10Y yield** (5-signal)
- 期間: 2019-10〜2026-04 (6.5 年)
- 比較: BH 6.5y (Sharpe 0.871), R5 v2 (Sharpe 0.933)
- **R5 からの improvement を確認**

両方の WF を走らせて比較する。

## 3. 実装方針

### データ取得

- `scripts/backfill-macro.ts` を拡張して `^TNX` を追加（既存の DXY/VIX と並列）
- MacroBar テーブルは ticker カラムで区別するだけ、schema 変更不要

### 2 つの engine

#### A. `continuous-sizing-v3-engine.ts` (4-signal, no funding)
- Signals: onchain + DXY + VIX + **TNX**
- TNX signal: 10Y yield の rolling percentile 低い = bullish (金利低水準 = 流動性緩和)
- 均等重み 0.25 each
- 10 年 WF 用

#### B. `continuous-sizing-v4-engine.ts` (5-signal)
- Signals: onchain + DXY + VIX + funding + **TNX**
- 均等重み 0.20 each
- 6.5 年 WF 用、R5 v2 との直接比較

### TNX signal 設計

- ^TNX はパーセント表記（4.5 = 4.5% yield）
- **Rolling percentile** (365 日) で regime 判定（R5 funding と同じパターン）
- 低 percentile = 金利低 = bullish (crypto に有利)
- 高 percentile = 金利高 = bearish (risk-off)
- Score: `1 - tnxPercentile`

### パラメータ

R5 v2 と同様、追加 param なし（TNX lookback は funding と同じ 365 固定）:
- 既存 grid: `dxySmaPeriod`, `vixThreshold`, `rebalanceThreshold`
- Engine A: 2 × 3 × 3 = 18 combos
- Engine B: 同じ（funding lookback も固定にして combo 増やさない）

## 4. 評価基準

### Engine A (10y)
- **Sharpe ≥ 1.0**: 主KPI、**本 repo 初達成を狙う**
- **Beats BH 10y (1.102)**: 最終目標
- Drop ≤ 30%: 維持
- DD ≤ 50%: 維持

### Engine B (6.5y)
- Sharpe > R5 v2 (0.933)
- Drop ≤ 30%
- Beats BH 6.5y (0.871)

### 判定

- **SAVED ★**: Engine A で Sharpe ≥ 1.0 AND Beats BH 10y → **本 repo 初の全 strict criteria pass**
- **IMPROVED**: Engine A Sharpe > R5 v2 AND drop ≤ 30% → 正方向の積み重ね
- **NO EFFECT**: TNX 追加で変化 ±0.05 以内 → 既存 signal と冗長
- **WORSE**: 10Y yield が crypto に対してノイズ → 4 signal に戻す

---

## 5. リスクと注意

1. **Signal 冗長性**: TNX と DXY は相関する場合あり（通貨と金利は連動）。追加で情報増えない可能性
2. **2022 バイアス**: 10Y yield は 2022 の crypto bear を強く説明する → IS に 2022 を含む window が異常に OOS 予測力を持つ可能性 → drop 急増リスク
3. **Signal 数の逓減**: 4→5 signal で各 signal の重み 0.20、誤検知への耐性は上がるが単一信号の sensitivity 低下
4. **Forward fill**: TNX も US 営業日のみ、既存 macro-loader で処理
