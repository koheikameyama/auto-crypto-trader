# Funding Rate Arbitrage Strategy

## 概要

Perpetual（無期限先物）の資金調達率（funding rate）を獲得する、デルタニュートラル戦略。

## 基本原理

### Funding Rate とは

- **定義**: Perpの価格を現物価格に近づけるための調整メカニズム
- **頻度**: 8時間ごと（UTC 00:00, 08:00, 16:00）
- **方向**:
  - 市場が強気（perp > spot）→ ロングがショートに支払う
  - 市場が弱気（perp < spot）→ ショートがロングに支払う

### なぜ利益が出るのか

多くの市場参加者はロング（買い）に偏る傾向があるため、funding rateは**構造的に正**になりやすい。

→ 我々は「現物ロング × perpショート」で、この資金調達を受け取る側になる。

## ポジション構成

```
現物（GMO Coin）: +0.01 BTC （ロング）
Perp（Binance）  : -0.01 BTC （ショート）
---------------------------------------------
Net Delta        : 0 BTC      （市場中立）
```

### デルタニュートラルのメリット

- 市場が上がっても下がっても、ポジション全体の価値はほぼ変わらない
- 方向を当てる必要がない（directionalリスクゼロ）
- Funding rateだけが純粋な収益源

## 収益構造

### 収益

1. **Funding rate収入**: 8時間ごとに受け取る
2. **GMO Coin maker rebate**: 現物買いで-0.05%（受け取り）

### コスト

1. **Binance perp fee**: ショート建てで0.02%〜0.04%
2. **スプレッドコスト**: 現物とperpの価格差
3. **Rebalanceコスト**: デルタ調整のための取引手数料

### 損益計算例

**前提**:
- BTC価格: ¥10,000,000
- ポジション: 0.01 BTC
- Funding rate: 0.01% （8時間あたり）

**収益**:
- Funding: ¥10,000,000 × 0.01 BTC × 0.0001 = ¥100 / 8h
- 年率換算: ¥100 × 3 × 365 ≈ ¥109,500 / year
- 投資額: ¥100,000（現物）+ 証拠金 → 年率10%程度

**コスト**:
- Binance fee（建玉時）: ¥10,000,000 × 0.01 × 0.0004 ≈ ¥40
- Rebalance（月1回程度）: ¥50〜¥100

→ **Net profit**: ¥109,500 - ¥480 - ¥600 ≈ **¥108,000 / year**（年率10.8%）

## エントリー条件

Funding rateが一定の閾値を超えたらポジションを取る:

```
Entry threshold: funding_rate > 0.01% (8h) かつ 3日間平均 > 0.008%
Exit threshold : funding_rate < 0.005% (8h) または 3日間平均 < 0.003%
```

※ 閾値はbacktest検証後に最適化予定

## リスク

### 1. Funding Rate 反転リスク

市場が急落してfunding rateがマイナスになると、我々が支払う側になる。

**対策**:
- 3日間平均がマイナスに転じたら即座にポジション解消
- 異常値（< -0.5%）でアラート

### 2. 清算リスク

Binance perpでショートポジションが清算されると大損失。

**対策**:
- 証拠金維持率を常に150%以上に保つ
- 120%以下になったら追加証拠金またはポジション縮小

### 3. スプレッドリスク

現物とperpの価格差が開くと、rebalance時にコストがかかる。

**対策**:
- 流動性の高い時間帯（日本時間夜〜深夜）にrebalance
- スプレッドが0.1%以上開いたら一時停止

### 4. 取引所リスク

取引所がダウン、出金停止等のリスク。

**対策**:
- 資金を複数取引所に分散（GMO + Binance）
- 定期的に利益を出金

## Directional戦略との違い

| 項目 | Directional（既存3bot） | Funding Arb |
|---|---|---|
| リターンドライバー | 市場方向 | Funding rate |
| リスク | ベータ（市場リスク） | キャリー（清算リスク） |
| 相関 | 高い（市場暴落で全滅） | 低い（市場中立） |
| 監視帯域 | 多い（予測モデル） | 少ない（閾値監視） |
| Sharpe期待値 | 1.0〜1.5 | 2.0〜3.0（低ボラ） |

→ **ポートフォリオの分散効果が非常に高い**

## バックテスト計画

Phase 0で実装予定:

1. 過去1年分のfunding rateデータを収集
2. 仮想P&Lをシミュレーション
3. 最適なentry/exit閾値を決定
4. Sharpe ratio、Calmar ratio、max drawdownを算出

→ Sharpe > 2.0 かつ max DD < 10% なら Phase 1 へ進む
